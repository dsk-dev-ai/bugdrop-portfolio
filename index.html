01 — About me

The builder behind the machine

I'm Darshan Sanjay Kachare, a Computer Science student who learns best by breaking things and then fixing them. I like cloud, web, and automation — the moment a stack trace turns into an "oh, that's why" is my favourite part of engineering.

BUG DROP is my portfolio with a twist: instead of a list of skills, it dispenses the superpowers I actually earned from bugs. Every capsule is a real incident, the fix, and the lesson I now carry into every project.

Built for the AWS Student Builder Challenge: Build Your Tech Superpower, deployed on AWS Amplify Hosting.

The creative feature

One lever. Twelve bugs. Zero regrets.

Every pull dispenses an incident postmortem: what broke, why, how I fixed it, and the superpower it left behind. Pull three times to unlock the secret capsule.

Superpower of the day: …

How it works: the machine reads capsule stories from assets/js/capsules.json. The optional AWS counter calls POST /pull (API Gateway → Lambda → DynamoDB) and falls back to a local count if the API is offline, so the feature never breaks.
